# Cartões de implementação

Cada cartão inicial delimita uma onda. Antes de implementar, dividir em tarefas
menores quando necessário usando [o template](../task-template.md), mantendo
dependências, arquivos permitidos e critério de fechamento da onda.

Os cartões das ondas [0](wave-0-foundation.md), [1](wave-1-video-cli.md),
[2](wave-2-detection.md), [3](wave-3-tracking.md), [4](wave-4-counting.md),
[5](wave-5-zones-heatmaps.md) e [6](wave-6-exports.md) registram entregas concluídas e evidências locais.
As ondas [7](wave-7-evaluation.md), [8](wave-8-experiments.md) e
[9](wave-9-jobs-api.md), [10](wave-10-web-workspace.md) e
[11](wave-11-analytics.md) registram baseline, estudos, a API, o workspace
e os analytics.
Próximo: [wave-12-acceptance](wave-12-acceptance.md).
O cartão da [onda 12](wave-12-acceptance.md) registra o teste local. Não há
onda seguinte. A `LICENSE` continua sem escolha.
Estado canônico das ondas: [workboard](../workboard.md).
