# Cartões de implementação

Cada cartão inicial delimita uma onda. Antes de implementar, dividir em tarefas
menores quando necessário usando [o template](../task-template.md), mantendo
dependências, arquivos permitidos e critério de fechamento da onda.

Os cartões das ondas [0](wave-0-foundation.md), [1](wave-1-video-cli.md) e
[2](wave-2-detection.md) registram entregas concluídas e evidências locais.
Próximo: [wave-3-tracking](wave-3-tracking.md).
Cartões das ondas 3–12 permanecem propostos, com critérios de trabalho futuro.
Estado canônico das ondas: [workboard](../workboard.md).
